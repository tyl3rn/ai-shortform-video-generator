Privacy policy

showrunner pi is a personal tool used only by its owner. It is not offered to anyone else.

Google Drive access

The app requests the drive.file scope, which only lets it see and manage files it created itself. It uploads the videos and caption text files it generates to the owner's own Google Drive, and deletes those same files after 14 days. It cannot read any other file in the Drive.

Data collection and sharing

The app collects no personal data, has no analytics, and shares nothing with third parties. Google sign-in credentials are stored only on the owner's own device.
